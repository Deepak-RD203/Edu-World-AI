## EduWorld AI

EduWorld AI is a Next.js application designed to make online learning smarter and more engaging. It combines AI capabilities with a modern frontend to provide interactive lessons, seamless navigation, and a polished UX for students and educators.
This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```
